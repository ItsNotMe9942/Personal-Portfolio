# Personal Portfolio

An independently designed and built personal portfolio from an earlier stage of my software development journey.

This repository is intentionally kept largely as it was originally built. The README was added retrospectively to provide context, document what I learned, and show the progression from my earlier projects to the work I am doing today.

## About

I built this portfolio independently using the skills I had developed through self-study and practical projects. I used documentation, search, videos and other learning resources when I needed to understand individual techniques, but the portfolio itself was not a follow-along tutorial: its design, structure and implementation were my own work.

At the time, I was focused primarily on web and software development and was using the portfolio to bring together the projects and technologies I had been learning.

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome / Fork Awesome
- ScrollReveal
- Typed.js

The portfolio also represented technologies I was learning at the time, including React, Python, Flask, MySQL and Git.

## Projects Represented

The site captured several stages of my early development journey:

- **Todo List** — an early JavaScript project focused on dynamically creating and manipulating page content.
- **Rock-Paper-Scissors** — an independently built JavaScript project and one of the first projects I was particularly proud of. It brought together concepts I had been learning into an application I designed and implemented myself.
- **React Jobs** — a React learning project built by following a tutorial step-by-step. It is included as evidence of what I was learning at the time, not presented as an independently designed application.
- **Weather App** — part of a progression from an early Python weather project, through a Tkinter GUI using live weather data, and later toward a Flask/browser-based version.

## What I Learned

Building the portfolio gave me practical experience combining HTML, CSS and JavaScript into a complete responsive site rather than treating them as isolated exercises. It also gave me experience with DOM manipulation, form validation, responsive navigation, animation libraries, project presentation and integrating external services.

One particularly useful lesson came from the original contact form. I initially implemented email sending directly from browser-side JavaScript using SMTP credentials. I later learned that credentials should never be embedded in client-side code. The email-sending integration has therefore been deliberately retired while the validation UI is retained as part of the historical project.

## Retrospective Context

This repository is a snapshot of where I was at that point in my development rather than a project I have retrospectively rewritten to match my current skills.

Some wording, design decisions and implementation choices reflect an earlier stage of my learning. I have deliberately preserved most of them because the purpose of keeping this project public is to document progression, not to make older work appear newer than it is.

The original downloadable CV has been removed because it was tailored to software-development roles I am no longer pursuing and no longer represents my current direction.

The contact form remains as a non-sending proof of concept for the original UI and validation work. Its client-side SMTP integration has been removed for security reasons.

## Development Journey

This portfolio sits within a wider progression that began with small JavaScript projects, grew into independent front-end and Python work, included structured learning projects such as React Jobs, and eventually led me away from front-end development toward cybersecurity and more systems-focused engineering.

My current work is represented by **Project Sentinel**, where those earlier programming foundations are now being applied to a larger security-focused engineering project.
